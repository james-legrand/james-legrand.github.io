ReFind

ReFind is a Firefox add-on that builds upon the default find feature. This add-on allows the user to perform a more advanced text search on a webpage. Beyond vanilla text searches, it can search based on regex patterns, and for combinations of words that appear in close proximity to one another.


Please note that this tool is for use on simple webpages only. Dynamic pages (like Google sites) are beyond the scope of ReFind.
